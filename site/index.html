Los 4 ejes — qué mide cada uno

Cada deducción trae file:line + severidad + fix. Un fix por eje por PR → de 4 a 6.5 en un sprint.

S

S — Security

R1 RISK

¿Se puede romper o filtrar? Secret en repo, `NEXT_PUBLIC_SECRET`, injection, XSS, validación, auth solo en cliente.

Si fallás: token filtrado, 500 en lugar de 404 tipado.

P

P — Performance

R4 RESILIENCE

¿Escala? N+1, listas sin paginar, `httpLink` sin batch, God component 250 líneas, bundle 1MB.

Fix: `httpBatchLink`, `staleTime`, paginación cursor.

C

C — Clean Code

R2 READABILITY

¿Se entiende en 5 seg? Inglés en lógica (no en datos de respuesta), SRP, ≤50 líneas, DRY, magic `86400` → `MAX_RETRIES`.

`getUserById` ✅ vs `funcion1` ❌ — pero `mensaje: "Todo creado"` ✅

O

O — Organization

R2 READABILITY

¿Se navega fácil? Screaming Architecture `features/todo/`, `kebab/Pascal/camel` consistente, atomicidad, boundaries.

Fix: `TodoItem.tsx` fuera de `page.tsx` 151 líneas.

Datos: 10 vs 4 — mismo Todo, distinto estándar

Basado en Todo-List-con-TRPC (docs/examples). /edu --quick te da el semáforo en 2 seg.

Glosario — si no sabés de qué trata, empezá acá

Términos del rubric y del día a día. Lógica en inglés, datos en español ✅ — ver edu-rubric#C1.

Conventional Commits commit

feat(todo): add TodoItem with a11y — tipo(scope): sujeto en inglés, imperativo, <72 chars. Nunca arreglado o primer commit. Un cambio lógico por commit. conventionalcommits.org

Commit atómico O4

1 commit = 1 idea. No mezcles feat+fix+refactor. Si tu git diff --stat muestra 8 archivos de dominios distintos, son 2-3 commits.

SRP — Single Responsibility C2

Una función hace UNA cosa. Mal: handleData() { fetch+validate+save+notify } → Bien: validateTodo() saveTodo() notifyTodoCreated(). ≤50 líneas, ≤3 params.

God Component P4/C3

Componente de 150+ líneas que hace query + mutations + state + handlers + JSX (ej. app/page.tsx:6 del Todo-List). Partilo en TodoItem + TodoForm + useTodos.

Screaming Architecture O1

La estructura grita el dominio, no el tipo. Mal: src/components|hooks|utils con 40 archivos mezclados. Bien: features/todo/{TodoList, TodoItem, useTodos, todo.schema.ts}.

N+1 P1

Loop que hace 1 query por fila: users.map(u => fetchPosts(u.id)). Solución: batch, include, Promise.all, paginación.

TRPCError vs throw S5

En tRPC nunca throw new Error("Todo no encontrado") (500 genérico). Usá throw new TRPCError({ code: "NOT_FOUND" }) — tipado y con código semántico.

httpBatchLink P3

tRPC: httpLink hace 1 request por procedure. httpBatchLink agrupa varias en un request. Mirá utils/providers.tsx:18.

Magic number C5

if (x > 86400) → const SECONDS_IN_DAY = 86400. Nombra lo que el número significa.

Local-first & .crisol infra

Resultados en .crisol/results/edu-score.json (gitignored) + historial .crisol/history/history.ndjson. CI solo en main y /edu manual. Ver .crisol/README.md.
